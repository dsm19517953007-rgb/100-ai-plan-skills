# 001 案例：莫奈《日出印象》的飞行世界

本记录从已完成的 001 工程文档、源代码与验收报告整理，整理日期为 2026-10-12。它记录案例证据，不代表本技能已在另一幅绘画或另一台机器上复做成功。大型工程、参考视频与成片不随技能分发。

## 输入与艺术基准

用户希望把《日出印象》做成能飞进去的 3D 世界：空间巨大、内容丰富、可创新、有运镜，仍保留原画元素。后来将作品确定为第一期展示，并要求加入自制轻音乐。

原画观察与三维作用：

| 观察 | 三维处理 |
|---|---|
| 面积很小的橙红太阳 | 全程方向锚点，用大面积冷蓝灰衬托 |
| 断续暖色倒影 | 形成引导入画的笔触路径 |
| 前景小舟与船夫 | 建立尺度、近景遮挡与掠过视差 |
| 左右港岸、桅杆、吊机、烟囱 | 建立空间边界与可穿行航道 |
| 灰蓝、青绿水面和软边晨雾 | 用破碎色块、低对比远景与分层雾组织纵深 |

画外港口、悬流和颜料潮汐属于原创扩展。参考图片中的位置比例是项目的视觉观察，不是历史测绘。

## v1 到 v2：为什么功能通过后仍需重构

第一版已经有真实三维、交互和可播放 MP4。用户仍不满意美感；关键镜头显示硬边建筑、规整码头、均匀灰天、球形树和光滑拱门的形体语言不统一。增加花岛厚度属于真实尝试，不能记录成已经达到艺术目标。

| 发现 | 第二版实际改动 | 可复用的判断 |
|---|---|---|
| 规则港口模型主导画面 | 港岸改用错落、重叠色块描述轮廓 | 从整体和侧面检查形体，不只给模型加纹理 |
| 天空缺少大形和绘画手势 | AI 生成油彩晨空；另建有位置、有厚度的笔触云 | 天幕只负责远景，空间感需由近中景几何提供 |
| 幻想元素像玩具乐园 | 重构为密集短笔触组成的卷曲潮汐和悬流 | 新结构共享原画调色、尺度和材质 |
| 笔触多却零散 | 按切向、法向和曲率成簇排列，改变厚度、尺度与密度 | 随机性服务于连续形体 |
| 功能结果掩盖美术问题 | 关键镜头视觉评阅与技术验收分开 | 可运行、可播放、美感和用户确认分别记录 |

用户提供的《星空》飞入参考用于学习完整构图、方向笔触组成曲面、近看厚度与远退回收。本期保留莫奈的日出、港湾及色彩秩序。原参考视频与抽帧为私有研究，不进入公开技能包；来源见 [music-and-sources.md](music-and-sources.md)。

## 实际几何与镜头

`src/world.ts` 构造不对称、有脊线和厚度的短笔触，并用实例化组织水面、港岸、云和颜料潮汐。巨大卷曲面具有底曲面与方向笔触层，依据镜头通道保留空隙；近中景船只、人物和工业轮廓有三维位置。`assets/dawn-sky-oil-v2.png` 是 AI 生成远景天幕，不能据此把整幅世界称为完全由三维几何构成。

72 秒镜头从原画辨识进入，贴水掠船、穿过桅杆、抬升揭示港湾、穿进颜料潮汐，最后回望日轮并回收构图。自由飞行保留鼠标转向、WASD 移动、Q/E 升降等操作。

`src/camera.ts` 先连续插值位置与单位方向，再在相机前方固定距离生成注视点，改善注视点穿越造成的急转。本例使用 500 米注视距离；复用时按世界尺度与观看对象选择，不把 500 米设为通用常数。

最终配乐成片：72.000 秒，1920×1080，H.264/yuv420p，30 fps、2160 帧，AAC 双声道 48 kHz，148,598,896 bytes。最终实测响度 −17.99 LUFS，真峰值 −2.00 dBTP，检查无意外静音或数字削波。实测值是此成片的事实，不是所有未来成片的固定目标。

本例支持“绘画识别 → 空间与笔触转译 → 关键镜头反馈 → 三维与镜头重构 → 确定时间导出 → 技术、画面、媒体验收”的方法。把它迁移到其他画作时，应重新识别画派、结构、调色和素材，再预览、导出及验收。
