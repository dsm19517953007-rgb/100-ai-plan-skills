# 原创配乐方法与来源记录

## 按真实镜头写音乐

先锁定镜头段落与总时长，再建立原创短动机、和声和声部。主题通过音域、音符密度、力度和空间宽度展开，回望时收束，结尾留余响。保留 MIDI 或乐谱、音符事件、分轨、作曲脚本与来源清单，便于复做和修改。

001 的《晨雾里的橙色》为 D 大调、80 BPM、3/4 拍、32 小节：每拍 0.75 秒，每小节 2.25 秒，共 72 秒。原创动机 F♯4 → A4 → E5 → D5，对应 MIDI 66、69、76、74。钢琴使用真实 pp 单音演奏新写乐谱；弦垫与空气垫为代码合成。没有使用现成歌曲。

| 镜头时间 | 音乐组织 |
|---|---|
| 0–15 秒：晨雾与船夫 | 稀疏钢琴、低音和薄空气垫，主题留停顿 |
| 15–29 秒：桅杆通道 | 稍丰富的分解和弦与中高音回应 |
| 29–39 秒：抬升港湾 | 旋律向上、弦垫渐入 |
| 39–55 秒：颜料潮汐 | 动机高八度展开，扩大音域和立体声空间 |
| 55–65 秒：回望日轮 | 降低音符密度，收束弦垫 |
| 65–72 秒：主题回归 | 柔和落点、余响淡出 |

新作品按实际镜头改变调性、节拍、段落与乐器，不必套用这套参数。音色采样与原创旋律分别标明。

## 从作曲到最终成片

001 原工程的复现步骤为下载单音、合成分轨、生成原始混音、两遍响度处理、混入成片、检查最终文件。相同工程结构下：

```powershell
python music/晨雾里的橙色/fetch_samples.py
python music/晨雾里的橙色/compose.py
python tools/mix-music.py
python tools/verify-music.py
```

作曲使用 Python 的 numpy、scipy、soundfile；混音与检查调用 FFmpeg/FFprobe，支持 PATH 或 `FFMPEG`、`FFPROBE` 环境变量。脚本属于原工程，本技能包不包含它们；新工程应生成自己的作曲、混音和验收工具。

最终混音中海港声景线性增益为 0.05，音乐为主。画面无需变化时复制视频流，再编码音频；检查原/新视频编码数据是否一致。只有原始 WAV 合格不能证明 MP4 已有音乐，验收最终成片的音轨、解码、峰值、响度、静音和代表段落听感。

001 最终实测 −17.99 LUFS、−2.00 dBTP；独立 WAV 为 72 秒、48 kHz、双声道 PCM_24。它们是案例结果，后续按发布需求选目标并重新测量。
